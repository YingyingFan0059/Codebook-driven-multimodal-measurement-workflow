# Qwen3 Archived Assets

This directory is preserved as archived research context.

It is not part of the maintained CBMA V1 workflow core and should not be treated as a stable user entry point. The code and scripts remain useful as method history, but the active release path is centered on `project_release/workflow/`.

## Status

- experimental
- archived research assets

## Boundary

Any local execution here assumes a user-managed environment and user-provided paths such as:

- `<project_path>`
- `<video_dir>`
- `<audio_dir>`
- `<model_path>`

For release onboarding, prefer the workflow core and the synthetic demo instead of this directory.
